## 💻 Local Setup

If you want to run this portfolio locally or customize it:

1.  **Clone the repository**
    ```bash
    git clone [https://github.com/rashminnn/rashminnn.github.io.git](https://github.com/rashminnn/rashminnn.github.io.git)
    ```
2.  **Navigate to the folder**
    ```bash
    cd rashminnn.github.io
    ```
3.  **Open `index.html`**
    Simply open the file in your preferred browser (Chrome, Edge, Firefox). No build step required!
